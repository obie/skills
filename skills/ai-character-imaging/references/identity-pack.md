# The canon identity pack

- **Newest wins.** Use the latest approved production plates as refs, not early
  concept art. Early eras carry an older or different face, and the model
  averages them in. Retire refs the owner has corrected away from.
- **3–6 refs, identity only.** Varied angles and light, neutral backgrounds,
  head and shoulders. Full-body refs make the model copy the outfit and pose.
- **Order matters.** Ref #1 weighs most. Put the most recent approved pick there.
- **Identity paragraph.** Words for what refs cannot pin down: face shape
  ("soft, rounded, cherubic"), eyes, brows, hair colour and length, skin tone,
  apparent age, build. Reuse it verbatim in every prompt.
- **Expressions.** Name one per prompt (laughing, mid-sentence, eyes closed,
  over-the-shoulder glance). Without it every plate gets the same half-smile
  copied from the refs.
- **Version the pack.** `pack-v3/` with a README of what changed and why, so a
  drift can be traced to a ref swap.
