# Rounds and owner review

1. One round = one brief (e.g. 6 slots x 6 candidates). Name files
   `r{round}-{slot}-{n}.png`.
2. Publish a voting gallery: large images, keep / maybe / reject, free-text note,
   state saved somewhere the agent can read back. No ZIPs of images to download.
3. The owner's notes are the spec. Turn each recurring note into a prompt rule
   or a never rule ("too old" → age phrase in identity; "hands on face" → "hands
   away from face").
4. Promote approved picks into the pack (ref #1) before the next round.
5. Stop a slot when it has one clear keep. Do not polish a slot nobody asked about.
6. QC each keep at 100% crop: eyes, teeth, hands, hairline, earrings, text.
